THOR: Thalamic Hub for Open-data Reuse

An interactive resource of publicly available whole-brain MRI datasets potentially suitable for thalamic nuclei research.

THOR summarizes key information across open neuroimaging datasets, including links to repositories and reference papers, number of subjects, available MRI contrasts, spatial resolution of the main T1-weighted structural imaging, and cohort characteristics.

This resource is intended as a practical starting point for dataset selection, helping researchers make informed decisions based on the anatomical and methodological requirements of thalamic investigations.
